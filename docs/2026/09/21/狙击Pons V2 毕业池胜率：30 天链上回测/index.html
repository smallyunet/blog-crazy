狙击Pons V2 毕业池胜率：30 天链上回测AI

2026-09-21

链上观察窗口： 2026-08-21 04:25 UTC 至 2026-09-20 03:40 UTC；Robinhood Chain 主网（chain ID 4663）。

结论

在可精确重放的 3,681 个原生 ETH 毕业池中，以 0.05 ETH 买入、5 分钟后全卖的固定交易量重放模型：B0 中位净收益率为 -15.3% ，胜率 39.7% ；B1 中位净收益率为 -16.5% ，胜率 38.7% 。这里的 B0/B1 都以我们取得该位置的交易排序为前提；它们不是已执行交易的收益，也不含抢排序失败的概率。

B0 的算术平均收益率为 +7.1%，符号为正；新币收益通常有长尾，所以主要判断应看中位数、胜率和尾部损失，而不是只看平均值。

样本和可比口径

  • 扫描当前 Pons V2 factory 的毕业事件 8,582 个，其中原生 ETH 配对 3,847 个。每个代币只出现一次毕业事件。
  • 连续核对 5,127 个日志区间，没有重复或越界；共取回并处理 8,189,970 条 V4 swap。该批池的 hook 费均为 1% ，创建者税另按币种计入。
  • 2,839/3,847 个 ETH 毕业币设置了非零创建者税，税率中位数为 100 bps ；因此只按池报价估算收益会漏掉重要成本。
  • 成功取回池历史 3,847 个；RPC/解析失败 0 个；因额外区间流动性、非零池费或重放误差排除 166 个；主模型覆盖 3,681/3,847（95.7%） 。排除池不记为零收益。
  • 排除池的 31 分钟 swap 数中位数为 3,999 ，保留池为 1,119 ；因此模型排除并非随机，尤其不能把主结果当作全部毕业池的无偏平均收益。
  • 主模型池在建池后同一区块出现其他 swap 的有 495/3,681（13.4%） ；毕业后约 31 分钟内的 swap 中位数为 1,119 。同一区块发生 swap 说明 B0 排序存在竞争，并不估计我们能否赢得排序。
  • 全部 ETH 池中 2,397/3,847（62.3%） 的毕业交易本身含有建池后的 V4 swap；在主模型池中为 2,301/3,681 ，这些池从初始化到该交易结束的代币边际价格变化绝对值中位数为 1.9% 。独立交易无法插入另一笔交易内部，因此 B0 使用毕业交易结束后的池状态，不把初始化价当成可买价格。
  • 在同一区块还有其他 swap 的 495 个主模型池中，B1 相对 B0 的代币边际价格变化中位数为 +8.3% 。这是价格路径差异，不能直接当成 B0 与 B1 的可得利润差。
  • 两种买入：B0 为建池交易结束后、同一区块内第一笔独立交易；B1 为下一区块第一笔交易。B1 买入前包含建池区块中真实发生的后续交易。
  • 买入金额分别为 0.01、0.05、0.1 ETH；全卖时间为买入后 1、5、30 分钟。收益均以 ETH 计价；每个代币在各情景中权重相同。

回放方法

  1. 通过 PoolGraduated 确定毕业区块、交易顺序、投入池中的 token/ETH；从同笔回执的 Uniswap V4 Initialize 与 ModifyLiquidity 事件读取初始价格和活跃流动性。从发行记录核对原生 ETH 配对与创建者税，从发行时冻结的 fee policy 读取 hook 费。
  2. 对每个固定 ETH 投入，用 V4 的整数舍入公式模拟精确输入买单，扣除买入输出代币上的 hook 费和创建者税。历史 swap 用事件中的输入量及真实顺序逐笔重放；到期后卖出全部买到的 token，再扣除卖出 ETH 输出上的相同费率。
  3. 同时保留 anchor 结果作敏感性对照：它以真实历史池状态卖出，但不把我们的入场价格冲击带入后续路径。主表使用 fixed-flow replay，因为它至少保留了自身买入后的价格影响。逐笔结果见 trades.csv。
  4. Gas 每条交易腿取该池毕业交易以外第一笔真实 swap 的 gasUsed × effectiveGasPrice，无独立 swap 时回退到全样本中位数。本批有效回执样本 3,847 个，每腿中位成本约 0.00003835 ETH 。净收益率 = (卖出实际 ETH − 买入 ETH − 两腿 Gas) / (买入 ETH + 买入 Gas)。

验证与解释边界

  • 对主模型池，使用真实每笔 swap 的输入量重算后验池价格，必须与事件价格吻合；有效池最大相对误差为 1.74e-18 。另有区间流动性变更的池不使用单一流动性模型。核查结果见 audit.json，具体排除清单见 metadata.json。
  • 固定交易量重放是假设其他人的交易仍按历史顺序、仍输入相同数量。真实交易者可能因我们的买入调整金额、取消交易或触发 MEV；该反应无法从已经发生的链上历史中观察。
  • B0 需要我们的交易在建池交易之后进入同一区块 。仅有毕业事件提醒不足以保证这一顺序；本研究未测量待处理交易可见性、提交延迟、排序竞价、失败交易或抢到首位的概率。B1 同样以能排在下一区块第一位为前提。
  • 卖出按目标时间前最后可见的池状态计算，假定能够及时提交且一次全部成交。Gas 取观察到的 swap 交易作为代理，可能与专门的抢跑/路由交易不同。结果应视为条件收益分布，而不是可直接执行的预期利润。
  • 当前只覆盖官方文档列出的 V2 factory 与原生 ETH 池；不是 V1、其他配对资产或未来新 factory 的结果。
